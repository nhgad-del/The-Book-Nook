# The Book Nook

## Project Overview

The Book Nook is a beginner-friendly, front-end website that presents a curated collection of books. It is designed for readers who want to browse books, discover titles by genre, and keep track of their favorites.

## Features

* Responsive homepage and navigation
* Book collection displayed as cards
* Search books by title or author
* Filter books by genre
* Add or remove books from favorites
* Favorites count and dedicated favorites section
* Mobile navigation menu

## Technology Stack

* HTML5 — page structure
* CSS3 — styling and responsive layout
* JavaScript — search, filtering, favorites, and navigation

No backend or database is required.

## Project Structure

* `index.html` — website structure
* `style.css` — visual design and responsive styles
* `script.js` — book data and interactive features

## How to Run Locally

1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` using the Live Server extension.

Alternatively, open `index.html` directly in a web browser.
